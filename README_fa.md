# Conv2Crypt


این یک روش جدید برای ایمن‌سازی داده‌های شماست. کانولوشن یک عملیات اساسی در پردازش سیگنال و تصویر است و روی ماتریس‌ها عمل می‌کند. این عملیات با دو ماتریس کار می‌کند. یکی داده و دیگری کرنل که در رمزنگاری از کرنل به عنوان کلید استفاده می‌کنیم.


مزایای conv2crypt : 
- می‌توان رمزهای زیادی داشت و رمزگشایی آنها با کرنل/کلید یکسان نتیجه یکسانی به ما می‌دهد. بنابراین می‌توانیم داده‌ها را به اشکال مختلف ذخیره کنیم.
- می‌توان یک کرنل/کلید با اندازه‌های مختلف ایجاد کرد.

معایب : 
- آخرین اندیس کرنل/کلید باید یک باشد

بنابراین تنها قانون آن این است که آخرین اندیس کرنل/کلید باید یکی باشد.

## چگونگی استفاده
برای استفاده از آن، conv2crypt.py و main.py را دانلود کنید، سپس main.py را اجرا کنید. می‌توانید conv2crypt.py را وارد کنید و از توابع conv_encrypt و conv_decrypt در هر کجا که می‌خواهید استفاده کنید.
